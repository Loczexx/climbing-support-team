# Baza wiedzy i źródła

## Hierarchia źródeł

1. przeglądy systematyczne i metaanalizy;
2. oficjalne wytyczne i stanowiska ekspertów;
3. randomizowane badania kontrolowane;
4. wysokiej jakości badania obserwacyjne;
5. inne źródła wyłącznie przy braku lepszych dowodów.

Każdy materiał w bazie powinien mieć populację, metodę, ograniczenia, obszar
zastosowania, datę i ocenę jakości. Wynik badania nie jest automatycznie
uniwersalną zasadą dla wspinaczy.

Nie zapisujemy tu pełnych publikacji bez potwierdzenia licencji. Katalog ma
przechowywać metadane, cytowania oraz przetworzone fragmenty dopuszczone do RAG.
